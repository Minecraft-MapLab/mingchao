# 清宵

- Java 26.3，16×9共144张锁定地图、288个双面展示框。
- 原画幅完整保留，2048×1152像素，不裁切、不补白。
- 单层白羊毛地面，墙下留空一格；午夜冻结，创造模式与作弊开启。
- 菜单名称：清宵。ZIP内只有一个`qingxiao`文件夹；出生点正前方为展示墙。
- 地图色是离线生成的锁定像素，不是自然地形采样。预览不是客户端截图。

公开副本和ZIP解包副本各17项结构核验通过，144个地图文件及last_id原字节保留；头像/玩家身份/进度不进入ZIP。当前原档有3个背框旋转180°；仅公开副本恢复这3处，通过同批构建参考完整NBT对比确认无其他实体语义变化，原档不改。尚未启动新的Minecraft客户端导入脱敏ZIP，视觉与新导入体验仍待确认。
