# 安装 Java 26.3 地图

1. 从[清宵v0.1.0 Release](https://github.com/Minecraft-MapLab/mingchao/releases/tag/qingxiao-v0.1.0)下载`mingchao-qingxiao-java26.3-v0.1.0.zip`及`SHA256SUMS.txt`。不要把仓库自动生成的Source code ZIP当存档。
2. 核对SHA-256。
3. 保存并退出Minecraft，解压ZIP，确认`qingxiao`文件夹内直接有`level.dat`。
4. 将整个`qingxiao`文件夹放进存档目录：Windows为`%APPDATA%\.minecraft\saves`，Linux为`~/.minecraft/saves`，macOS为`~/Library/Application Support/minecraft/saves`。
5. 使用Java 26.3启动，在单人游戏列表选择“清宵”。不要覆盖任何已有同名文件夹；重命名新文件夹即可。

首入没有作者玩家位置、背包、统计或成就；游戏会为你建立自己的玩家记录。此存档不是基岩版`.mcworld`。不附JAR或启动器，也不要求登录第三方网站。
