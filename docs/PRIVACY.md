# 公开存档隐私范围

已从公开副本排除整个players目录、玩家备份/统计/进度、level.dat_old、session.lock、原自动截图icon、日志与未在白名单内的文件。level.dat去除Player、singleplayer_uuid、ServerBrands；LastPlayed改为公开版本日期。MCA内部4KiB时间表清零，不保留真实墙钟游玩/保存时刻；地图GZIP头本来不含时间或原文件名。图标从地图像素重新生成并清除PNG附加元数据。

完整地图、地图ID、实体随机UUID、方块区域、世界种子、游戏tick及必要规则/时钟仍保留，防止破坏地图与展示框关系。MCA除时间头外保留原载荷；唯一例外是公开副本中3个背框的180°旋转，仅在完整带类型NBT证明其余数据一致后从同批构建参考恢复。这些世界数据仍可能用于关联同一作品，本处理不是不可关联匿名化保证。

检查覆盖已知账号标识及解码NBT/文本中的本机路径和高置信凭据模式；未安装外部专用secret scanner，不能据此声称穷尽一切未知隐私渠道。未包含任何本机运行报告、开发环境、原图路径、账号配置或凭据。

ZIP统一条目日期/权限，无本机绝对路径、属主和备注字段。原游戏存档只读，脱敏不影响作者当前进度。发行包的技术检查不等于版权许可或客户端新导入测试。
